# Jobsammler

Sammelt jeden Morgen offene Stellen aus verlässlichen, strukturierten Quellen (Bewerbungssysteme von Firmen, Jobbörsen von VC-Fonds, Arbeitnow, Jobsuche der Bundesagentur für Arbeit) und schreibt sie nach `data/jobs.json`.

Eine Stelle gilt als offen, wenn sie heute in der Quelle steht. Fehlt sie, gilt sie als geschlossen.

*Im Aufbau. Wie man Firmen hinzufügt, steht hier, sobald das Programm fertig ist.*
